Both hunters sense about as often, but the network waits for the moment the player is afraid (close to him or just seen), so its senses pay off more often. Nobody wrote that rule.

How to read these numbers

  • The simulated survivors are rule-based bots, so these rates measure the brain against a fixed opponent, not against humans. Humans hide in unexpected places and use horns; in the game Freddy is beatable.
  • The game also makes him slower on night 1 (a decision every 3.5 s) and gives the player a head start during the phone call.
  • Reproduce: open the Unity project, menu Night Shift → Build Evaluation, run the build, then python scripts/summarize_eval.py.
